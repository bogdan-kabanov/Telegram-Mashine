# iostgico

Telegram iOS icon font from the community [Telegram IOS UI Kit](https://www.figma.com/community/file/1342906900898425723/telegram-ios-ui-kit) (Private Use Area glyphs).

| File | Family |
|------|--------|
| `iostgico.ttf` | iostgico |

Used for chat chrome icons (attach, sticker, mic, back chevron) in Playwright screenshots and the admin phone preview.

| File | Notes |
|------|--------|
| `iostgico.ttf` | Original COLR color font (#008bff) |
| `iostgico-mono.ttf` | Glyf-only copy used in app — CSS `color` works |
